# Передача контекста в новую сессию

Переписку передавать не нужно и незачем: весь контекст программы живёт в
документах. Этот файл — готовый текст для вставки первым сообщением в новый
чат на любой машине.

## Что вставить в новый чат

Скопируй всё между линиями.

---

Это репозиторий `tempocue-vision-model` — обучение модели распознавания
миникарты League of Legends для приложения TempoCue. Я новичок в ML, объясняй
без жаргона и говори, что делаешь и зачем. Отвечай по-русски.

Прочитай в этом порядке, этого достаточно, чтобы продолжить без пересказа
истории:

1. `AGENTS.md` — правила работы: решения только в документах, критерии до
   запуска, корпус никогда не обучение, проверка глазами до статистики.
2. `docs/code-style.md` — правила кода, `ruff format` и `ruff check` перед
   каждым коммитом.
3. `docs/commits.md` — Conventional Commits, русское тело, без
   `Co-Authored-By`.
4. `README.md` — устройство репозитория и ступени программы.
5. `docs/render-verification.md` — ступень 1, завершена: значок миникарты
   воспроизводится из circle-иконок игры, параметры отрисовки измерены.
6. `docs/generator.md` — ступень 2: генератор синтетики и вердикт судьи
   доменов.
7. `docs/training-runbook.md` — как запускать генерацию датасета и обучение.

Полный план программы лежит в соседнем репозитории TempoCue,
`docs/own-model-plan.md` — это точка входа со всеми измерениями, архитектурой
и порогами приёмки. Если этого репозитория на машине нет, работай по
документам выше.

## Где лежат сырые записи сессий

Claude Code хранит их локально:

```
C:\Users\<пользователь>\.claude\projects\<путь-проекта>\*.jsonl
```

Файлы большие (десятки мегабайт на сессию) и не предназначены для вставки в
чат: это служебный формат со всеми вызовами инструментов. Передавать их не
нужно — тексту выше достаточно.

## Почему так устроено

Правило программы: **решение, не записанное в документ, не существует**.
Переписка не переживает смену сессии и машины, документы переживают. Если в
разговоре появилось что-то важное, оно должно оказаться в `docs/` тем же
изменением — тогда следующая сессия начинается с чтения, а не с пересказа.
