# ADR этого репозитория

ADR (Architecture Decision Record — запись архитектурного решения) фиксирует
осознанное решение, его причины и отвергнутые альтернативы, чтобы через месяцы
не восстанавливать логику по памяти.

Разграничение: решения **уровня программы** — архитектура модели, данные,
приёмка — живут в `own-model-plan.md` основного репозитория TempoCue. Здесь —
только решения об **устройстве этого репозитория**: структура, зависимости,
форматы промежуточных артефактов, схема датасета.

Формат — как в основном репозитории (`docs/adr/0001-…`):

```markdown
# NNNN. Название решением, а не темой

- Статус: принято | заменено NNNN
- Дата: YYYY-MM-DD

## Контекст
## Решение
## Альтернативы
## Последствия
```

Файлы нумеруются подряд: `0001-kebab-case-название.md`.
